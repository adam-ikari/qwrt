qwrt HTTP Server

基于 qwrt 能力搭建的完整 HTTP 服务器（应用层实现）

功能演示

  • 路由：/api/hello、/api/echo（POST）、/api/cache
  • 静态文件：本页面 + /style.css + /app.js
  • 缓存：内存 LRU + ETag 协商（刷新看 304）
  • 压缩：本 HTML 超过 1KB，接受 gzip 的客户端会收到 Content-Encoding: gzip
